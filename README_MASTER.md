## 🚀 البداية السريعة (Quick Start)

### 1. تثبيت البيئة
```bash
pip install -r requirements.txt
```

### 2. توليد بيانات التدريب
```bash
python مجموعات_البيانات/csprng_generator.py
python مجموعات_البيانات/prepare_real_dataset.py
```

### 3. تدريب النماذج
```bash
python src/train.py --steps 5000 --batch_size 256 --n_bits 16 --k_eve 2
```

### 4. التقييم الأمني الشامل
```bash
python src/evaluate.py
python src/sac_eval.py
python src/nist_eval.py
python src/fault_injection.py
python src/aes_benchmark.py
```

### 5. لوحة التحكم التفاعلية
```bash
streamlit run dashboard/app.py
```

## 🗂️ هيكلية المجلدات

| المجلد / الملف | الوصف |
|:---|:---|
| `src/` | الكود البرمجي الأساسي (النماذج، التدريب، التقييم) |
