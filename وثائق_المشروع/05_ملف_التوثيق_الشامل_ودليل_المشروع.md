## 2. الملخص التنفيذي للمنظومة (Executive Summary)

يمثل مشروع **NeuroCrypt-Guard** نقلة نوعية في أبحاث التشفير التنافسي القائم على الذكاء الاصطناعي (Adversarial Neural Cryptography)؛ حيث نجح في معالجة أوجه القصور الهندسية والرياضية التي تركتها ورقة Google Brain الأصلية (Abadi & Andersen, 2016). 

يقوم النظام على ثلاث شبكات عصبية عميقة (AliceNet, BobNet, EveNet) تم تدريبها بآلية تنافسية غير متناظرة مدعمة بدالة تكلفة مقيدة تربيعياً لمنع ظاهرة "التشفير المعكوس"، ونجح عملياً في تحقيق دقة فك تشفير تكاد تكون تامة للطرف الشرعي (**$99.72\%$**) مع حصر المتنصت الخصم عند حدود التخمين الأعمى العشوائي (**$BER \approx 44\%$**)، محققاً فجوة أمنية قياسية بلغت **$43.29\%$** وموثقة على بيانات اختبار مستقلة وداتا سيت نصوص حقيقية.

قم بفتح الطرفية (Terminal / PowerShell) في المجلد الرئيسي للمشروع ونفذ الأمر التالي لتثبيت كافة التبعيات:
```bash
pip install -r requirements.txt
```

### 3.2 أوامر التشغيل التنفيذية (Execution Commands):

#### 1. توليد واختبار البيانات العشوائية التشفيرية (CSPRNG):
* **تشغيل الفحص الذاتي للمولد والتأكد من التوزيع الإحصائي:**
  ```bash
  python مجموعات_البيانات/csprng_generator.py --test
  ```
* **تصدير مليون بت عشوائي لفحص NIST:**
  ```bash
  python مجموعات_البيانات/csprng_generator.py --nist --bits 1000000 --out nist_bits.bin
  ```

#### 2. معالجة وتجزئة مجموعة البيانات الحقيقية (Sherlock Holmes Corpus):
```bash
python مجموعات_البيانات/prepare_real_dataset.py
```
*المخرجات:* كتل ثنائية مضغوطة بأطوال 16 و 32 و 64 بت مقسمة 80% تدريب و 20% اختبار في مجلد `real_corpora/`.

#### 3. تشغيل محرك التدريب التنافسي (Train Neural Cryptosystem):
* **تشغيل دورة تدريبية سريعة (2,000 خطوة مع تسريع CUDA):**
  ```bash
  python src/train.py --steps 2000 --batch_size 256 --msg_len 16 --k_eve 2 --print_every 200
  ```
* **خيارات سطر الأوامر (Arguments):**
  * `--steps`: عدد خطوات التدريب (الافتراضي: 3000).
  * `--batch_size`: حجم دفعة الرسائل في كل خطوة (الافتراضي: 256 أو 512).
  * `--msg_len`: طول الرسالة والمفتاح بالبت (16، 32، 64).
  * `--lr`: معدل التعلم لمحسن Adam (الافتراضي: 0.0005).
  * `--k_eve`: عدد خطوات تدريب إيف لكل خطوة لأليس وبوب (الافتراضي: 2).
  * `--save_dir`: مسار حفظ أفضل النماذج (الافتراضي: `checkpoints`).

#### 4. فحص وتقييم النماذج المدربة (Security Evaluation):
```bash
python src/evaluate.py --msg_len 16 --checkpoint_dir checkpoints --num_samples 5000
```
*يقوم الفاحص تلقائياً بتحميل الأوزان المحفوظة واختبارها على 5,000 عينة عشوائية مستقلة وعلى كتل النصوص الحقيقية وطباعة تقرير الفجوة الأمنية.*

#### 5. توليد وثائق المقترح النهائي بجميع الصيغ (PDF + Word + LaTeX):
```bash
python build_exact_proposal.py
```
*يقوم بإنشاء ملف PDF المطابق لقالب جامعة إب، وملف Word، وملف LaTeX في المجلد الرئيسي.*

## 4. المرجع البرمجي للمنظومة (Codebase API Reference)

### 4.1 حزمة النماذج العصبية (`src/models.py`):
* `class AliceNet(nn.Module)`:
  * **المدخلات:** `(message: Tensor, key: Tensor)` بحجم `(Batch, N)`.
  * **المعمارية:** `Linear(2N, 2N)` $\to$ `Conv1d(1, 32)` $\to$ `Conv1d(32, 32)` $\to$ `Conv1d(32, 1)` $\to$ `Linear(2N, N)` $\to$ `Tanh()`.
  * **المخرجات:** `ciphertext` بحجم `(Batch, N)` في المجال $[-1.0, 1.0]$.
* `class BobNet(nn.Module)`:
  * **المدخلات:** `(ciphertext: Tensor, key: Tensor)` بحجم `(Batch, N)`.
  * **المخرجات:** `decrypted` بحجم `(Batch, N)` يمثل الرسالة المستعادة $P'$.
* `class EveNet(nn.Module)`:
  * **المدخلات:** `(ciphertext: Tensor)` بحجم `(Batch, N)`.
  * **المعمارية:** طبقة توسيع `Linear(N, 2N)` تليها 3 طبقات التفاف عريضة (48 قناة) لتمثيل الخصم الأمثل.
  * **المخرجات:** `eavesdropped` بحجم `(Batch, N)` يمثل تخمين إيف $P''$.

### 4.2 حزمة دوال الخسارة والتقييم (`src/loss.py`):
* `normalized_l1_distance(actual, predicted)`: حساب متوسط المسافة المطلقة المقيسة بين $[0.0, 1.0]$.
* `calculate_ber(actual, predicted)`: حساب نسبة البتات الخاطئة في التخمين (Bit Error Rate).
* `loss_eve(actual, eve_guess)`: دالة خسارة إيف لتقليل مسافة التخمين نحو الصفر.
* `loss_alice_bob(actual, bob_dec, eve_guess, security_margin=0.5)`: دالة التكلفة المقيدة تربيعياً؛ تعاقب النموذج إذا كان خطأ إيف $< 0.5$ وتمنع حدوث التشفير المعكوس.

## 6. إرشادات الأمان والمحاذير الهندسية (Operational Safety Guidelines)

1. **إدارة المفاتيح السرية (Key Management):**  
   يجب أن يتم توليد المفتاح السري $K$ باستخدام مولدات تشفيرية معتمدة (مثل `os.urandom` أو `secrets`)، ولا يجوز إعادة استخدام المفتاح نفسه لتشفير رسائل مختلفة إذا كانت متطابقة لتجنب هجمات كشف الأنماط.
2. **عتبة حيرة المتنصت (Eve BER Threshold):**  
   لا يُعتبر النموذج مدرباً بنجاح إذا كان خطأ إيف أكبر بكثير من $50\%$ (مثلاً $80\%$ أو $100\%$)؛ لأن ذلك يشير إلى وقوع النظام في ثغرة "التشفير المعكوس"، حيث يمكن للمتنصت قلب البتات واستعادة النص الأصلي. نجاح التدريب يتطلب بقاء خطأ إيف متذبذباً بين **$42\% - 50\%$**.
