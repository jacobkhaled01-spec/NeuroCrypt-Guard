# دليل مجلد الأوراق العلمية والدراسات المرجعية (Papers & Literature Review)

يحتوي هذا المجلد على بطاقات تحليلية ونقدية لأهم الأوراق العلمية والمعايير العالمية التي يقوم عليها مشروع **NeuroCrypt-Guard**. تم تصميم هذه البطاقات لتكون مصدراً جاهزاً للاقتباس والاستخدام المباشر في فصول تقرير المشروع (خصوصاً فصلي: **مراجعة الأدبيات Literature Review** و**المنهجية Methodology**).

1. **[`01_Abadi_Google_Brain_2016.md`](file:///d:/IT%20FILES/level%204/تشفير/عملي/مشروع/الأوراق_والدراسات/01_Abadi_Google_Brain_2016.md)**

5. **[`05_Fault_Injection_Studies.md`](file:///d:/IT%20FILES/level%204/تشفير/عملي/مشروع/الأوراق_والدراسات/05_Fault_Injection_Studies.md)**
